# SoundFlow 4.0.1

- Comprobación automática de versiones al abrir o volver a la aplicación y cada
  cinco minutos mientras está visible. Respeta la opción de privacidad de Ajustes.
- Aviso automático de actualización una sola vez por versión, conservado al cerrar
  y reabrir. La consulta manual permite recuperar la actualización cuando quieras.
- Ventana con versión instalada y novedades una sola vez después de instalar o
  actualizar, disponible también sin conexión.
- Los avisos de novedades y actualización se presentan por separado.
- Se conservan la verificación del APK, la firma compatible y la confirmación
  mediante el instalador Android. Favoritos, playlists y biblioteca sin cambios.

La app cerrada no recibe notificaciones push de GitHub. Para detectar una release
nueva, abre SoundFlow con conexión y la comprobación de actualizaciones activada.
